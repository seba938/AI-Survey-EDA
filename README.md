# AI-Survey-EDA
# Analisi esplorativa: percezione e uso dell'AI

Progetto personale per imparare l'analisi dati in Python.
Analisi di un sondaggio di 205 rispondenti su uso, fiducia e percezione dell'intelligenza artificiale.

## Strumenti
Python · pandas · seaborn · matplotlib · SciPy

## Domande
- L'uso dell'AI varia in base a titolo di studio, età, genere o situazione lavorativa?
- Chi passa più tempo sui dispositivi usa di più l'AI?

## Risultati principali
- L'uso dell'AI è significativamente più alto tra i giovani (18–24) e gli studenti (p < 0,001)
- Cresce con il tempo trascorso sui dispositivi (Spearman ρ = 0,27)
- Nessuna differenza significativa per titolo di studio o genere
- Età e situazione lavorativa si sovrappongono: probabile fattore confondente
